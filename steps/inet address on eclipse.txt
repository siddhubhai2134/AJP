Step-by-Step Process to Execute InetDemo2.java

This Java program:

uses InetAddress
gets localhost information
displays host name and IP address
Step 1: Open Eclipse IDE

Start Eclipse IDE

Step 2: Create Java Project

Click:

File → New → Java Project

Project name:

InetProject

Click:

Finish
Step 3: Delete module-info.java

If present:

right click
delete

This avoids module issues.

Step 4: Create Package

Right click:

src

Select:

New → Package

Package name:

network

Click Finish.

Step 5: Create Java Class

Right click package:

network

Select:

New → Class

Class name:

InetDemo2

Tick:

public static void main(String[] args)

Click Finish.

Step 6: Remove Default Code

Delete default code generated by Eclipse.

Step 7: Paste Program

Paste:


import java.io.*;
import java.net.*;

public class InetDemo2
{
    public static void main(String[] args)
    {
        try
        {
            InetAddress ip = InetAddress.getByName("localhost");

            System.out.println("Host Name: " + ip.getHostName());
            System.out.println("IP Address: " + ip.getHostAddress());
        }
        catch(Exception e)
        {
            System.out.println(e);
        }
    }
}
Step 8: Save Program

Press:

Ctrl + S

If no red errors appear → compilation successful.

Step 9: Run Program

Click:

Run → Run As → Java Application

OR click green ▶ Run button.

Expected Output
Host Name: localhost
IP Address: 127.0.0.1
