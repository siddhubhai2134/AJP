Step-by-Step Process to Execute ReportCard.java in Eclipse
Step 1: Open Eclipse IDE

Start Eclipse IDE

Step 2: Create Java Project

Click:

File → New → Java Project

Project Name:

SwingProject

Click:

Finish
Step 3: Delete module-info.java

In Package Explorer:

Find:

module-info.java

Right click → Delete → OK

This avoids Swing/AWT module issues.

Step 4: Create Package

Right click:

src

Select:

New → Package

Package name:

mypackage

Click Finish.

Step 5: Create Java Class

Right click package:

mypackage

Select:

New → Class

Class name:

ReportCard

Tick:

public static void main(String[] args)

Click Finish.

Step 6: Remove Default Code

Delete the default code created by Eclipse.

Step 7: Paste Full Program

Paste your complete ReportCard program.

Step 8: Save the Program

Press:

Ctrl + S

Eclipse automatically compiles the code.

If no red errors appear → program compiled successfully.

Step 9: Run the Program

Click:

Run → Run As → Java Application

OR click green ▶ Run button.

Step 10: Program Output

A Swing form window opens.

Fields displayed:

Name
Math Marks
Science Marks
English Marks

Button:

Submit
